Project Overview:
Developed an interactive Power BI dashboard to analyze Blinkit grocery sales data and identify sales trends, outlet performance, and product category insights.

Key Performance Indicators (KPIs)
•	Total Sales: 18.59 Million
•	Average Sales: 2.18K
•	Total Records: 8,523
•	Average Item MRP: ₹141.00

Dashboard Features
•	Outlet Establishment Trend Analysis
•	Sales by Fat Content
•	Sales by Item Type
•	Sales by Outlet Size
•	Sales by Outlet Location
•	Outlet Type Performance Matrix
•	Interactive slicers for outlet location, outlet size, and item type

 Key Insights
•	Analyzed sales performance across different outlet types.
•	Compared sales contributions by fat content and item categories.
•	Evaluated outlet performance across Tier 1, Tier 2, and Tier 3 locations.
•	Created interactive filters for detailed business analysis.
